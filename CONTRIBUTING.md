# Contributing

Thank you for helping improve AI Creations Now public documentation and software quality.

## Welcome contributions

This repository welcomes documentation corrections, broken-link reports, reproducible AINowBench bug reports, non-sensitive result-upload reports, clear feature requests, and accessibility or usability suggestions.

## Before opening an issue

1. Confirm you are using the current documented release.
2. Review the installation, troubleshooting, and FAQ pages.
3. Search existing issues for the same behavior.
4. Remove personal, customer, and account information.
5. Use the matching structured issue form.

## Pull requests

A pull request should have one clear purpose, explain what changed and why, use relative links for repository documents, and preserve the published product boundaries. Do not change official download hashes, release versions, pricing, legal notices, or support claims without approval from the release owner.

Only submit text, code, and artwork that you have the right to contribute. Public documentation does not mean every AI Creations Now product is open source; proprietary implementation materials are outside the scope of this repository.

Participation is governed by [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md). Security-sensitive matters must follow the private process in [SECURITY.md](./SECURITY.md).
