# Contributing to AINowBench Documentation

This repository is dedicated exclusively to AINowBench. The proprietary application source code is not published, and public source-code contributions are not accepted.

Useful public contributions include:

- AINowBench documentation corrections
- Broken-link reports
- Reproducible, non-sensitive benchmark defects
- Compatibility observations with exact Windows and hardware details
- AINowBench usability, reporting, or accessibility suggestions

Before opening an issue:

1. Confirm you are using the current production release.
2. Review the installation, troubleshooting, and FAQ documents.
3. Search existing issues for the same behavior.
4. Remove personal, customer, account, and security-sensitive information.
5. Use the matching structured issue form.

Do not change official hashes, release versions, scoring claims, or legal notices without approval from the release owner. Security-sensitive matters must follow [SECURITY.md](./SECURITY.md).
