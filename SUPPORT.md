# AINowBench Support

Use this repository's structured issue forms for public, non-sensitive AINowBench matters:

- Reproducible benchmark defects
- Benchmark-result or upload problems
- Documentation corrections
- AINowBench feature requests

Before submitting, review:

- [Installation](./docs/ainowbench/INSTALLATION.md)
- [Verification](./docs/ainowbench/VERIFY_DOWNLOAD.md)
- [Troubleshooting](./docs/ainowbench/TROUBLESHOOTING.md)
- [FAQ](./docs/ainowbench/FAQ.md)
- [Results and privacy](./docs/ainowbench/RESULTS_AND_PRIVACY.md)

## Include

- AINowBench version
- Windows edition and build
- Processor and graphics adapter
- Installed memory and system-drive type
- Exact benchmark stage or result row
- Expected behavior and actual behavior
- Reproduction steps
- A short, redacted error excerpt

## Remove before posting

Do not publicly post computer names, Windows usernames, local paths, email addresses, phone numbers, private installation identifiers, credentials, tokens, unredacted logs, or customer information.

Security-sensitive reports belong under the private process in [SECURITY.md](./SECURITY.md).
