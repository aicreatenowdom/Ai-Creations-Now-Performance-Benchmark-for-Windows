# Support

## AINowBench community support

Use the GitHub issue forms for:

- Reproducible AINowBench bugs
- Benchmark-result or upload problems
- Documentation corrections
- Public feature requests

Before submitting, review:

- [Installation](./docs/ainowbench/INSTALLATION.md)
- [Verification](./docs/ainowbench/VERIFY_DOWNLOAD.md)
- [Troubleshooting](./docs/ainowbench/TROUBLESHOOTING.md)
- [FAQ](./docs/ainowbench/FAQ.md)
- [Results and privacy](./docs/ainowbench/RESULTS_AND_PRIVACY.md)

## Information to include

A useful non-sensitive report includes:

- Product and version
- Windows edition and build
- Processor model
- Graphics adapter
- Installed memory
- System-drive type
- Exact benchmark stage or result row
- Expected behavior
- Actual behavior
- Reproduction steps
- A short, redacted error excerpt

## Information to remove

Do not publicly post:

- Computer name
- Windows user name
- Local paths
- Email address
- Phone number
- Private Installation ID
- Credentials or tokens
- Raw unredacted technical TXT
- Raw unredacted diagnostic log
- Signing account information
- Customer or licensing data
